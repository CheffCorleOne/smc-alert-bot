### 3. SIGNAL DEDUPLICATION
Add a simple in-memory dict: `notified_signals: dict[str, str]`
Key = symbol, Value = signal direction + entry_price rounded to 5 decimal places
  (e.g. "buy_1.08523")

Logic in _analyze_single_symbol():
- When a signal fires: check if notified_signals[symbol] == current signal key
  - If YES and user has NOT acknowledged → re-send only if last_sent_time > 5 minutes ago
  - If YES and user HAS acknowledged (placed order) → skip, do not re-send
  - If NO (new signal) → send Telegram message, store in notified_signals
- When signal disappears (no signal on scan) → clear notified_signals[symbol]
  and reset acknowledgement

Acknowledgement mechanism:
- Telegram inline keyboard button under each signal: "✅ Order Placed"
- When user taps it → bot receives callback, marks that symbol as acknowledged
  Store in: `acknowledged_signals: dict[str, str]` (symbol → signal_key)
- Add /status command: shows all active signals and which ones are acknowledged

### 4. NEW FILE — `telegram_notifier.py`
Create this file in the root of the project.

Class TelegramNotifier:
  - __init__(token, chat_id): store token and chat_id
  - send_signal(signal, lot, estimated_hours): sends formatted message with inline button
  - handle_callback(callback_query): processes "Order Placed" button taps
  - start_polling(): starts async polling in a background thread
  - /status command handler: shows current active signals

Signal message format:
🟢 EURUSD BUY   (or 🔴 for SELL)
━━━━━━━━━━━━━━
📦 Lot Size:  0.10
🎯 Entry:     1.08523
🛑 Stop Loss: 1.08250  (-27 pips)
✅ Take Profit: 1.09100  (+57 pips)
📊 RR Ratio:  1:2.4
⭐ Score:      78/100
⏱ Est. hold:  ~3-5 hours
📍 Session:   New York
━━━━━━━━━━━━━━
[✅ Order Placed]
Estimated hold time logic (heuristic based on session + RR):
- Asian session: RR * 3 hours (slow session)
- London session: RR * 1.5 hours
- New York session: RR * 2 hours
- London Close: RR * 1 hour
- Default: RR * 2 hours
- Round to nearest 0.5h, format as range ±0.5h
  Example: RR=2.4, NY → 4.8h → "~4.5-5 hours"

Use python-telegram-bot library (v20+, async).

### 7. MAIN.PY — Integration
In _analyze_single_symbol(), after signal quality check, replace order execution with:
  notifier = bot_state["notifier"]
  if notifier:
      signal_key = f"{signal.direction}_{round(signal.entry_price, 5)}"
      already_acked = bot_state["acknowledged_signals"].get(base_symbol) == signal_key
      if not already_acked:
          lot = risk_mgr.calculate_lot_size(mt5_symbol, sl_pips, config.risk_per_trade_pct)
          estimated_hours = notifier.estimate_hold_time(signal.session, signal.rr_ratio)
          notifier.send_signal(signal, lot, estimated_hours)
          bot_state["notified_signals"][base_symbol] = signal_key

Add to bot_state:
  "notifier": None
  "notified_signals": {}
  "acknowledged_signals": {}

In main():
  Initialize TelegramNotifier if config.telegram_token and config.telegram_chat_id are set
  Start its polling thread
  Store in bot_state["notifier"]
